# Golden Pearl Immersive Showcase 🏛️✨

This project contains your "Golden Pearl Immersive Showcase" website imported directly from Google Stitch! It is a prestigious, premium, high-contrast website designed with Minimalist Luxury aesthetics, custom scroll effects, sharp edges, and elegant typography.

## Structure
- [index.html](file:///home/arjun/.gemini/antigravity-ide/scratch/golden-pearl/index.html) — The home page, featuring the custom parallax hero section, sticky header transitions, full-screen scrollytelling cards for mission/vision, and a dynamic services showcase grid.
- [services.html](file:///home/arjun/.gemini/antigravity-ide/scratch/golden-pearl/services.html) — The services & capabilities page highlighting industrial & civil construction, MEP systems, and luxury landscaping with smooth scroll reveals and horizontal parallax effects.

## Design Highlights
1. **Obsidian & Gold Color System**: Obsidian black canvas (`#000000`) and charcoal panels paired with luxurious metallic brushed gold (`#d4af37`) accents.
2. **Sharp, Precise Geometry**: Shape language is strictly sharp-edged (no rounded corners) to evoke structural and architectural rigidity.
3. **Advanced Micro-interactions**:
   - **Hero Parallax Zoom**: The background image scales and translates smoothly as you scroll.
   - **Scroll Reveals**: Sections slide and fade in gracefully (from left, right, or bottom) as they enter the viewport.
   - **Horizontal Parallax**: Background imagery moves slightly horizontally as you scroll.
4. **Tailwind JIT Integration**: Responsive layouts powered by Tailwind CSS CDN.

## Launching the Site

To run this site on a different port so it doesn't conflict with your BookZero server (running on `8000`):

1. Start a python server in the `/home/arjun/.gemini/antigravity-ide/scratch/golden-pearl` directory:
   ```bash
   python3 -m http.server 8001
   ```
2. Open **[http://localhost:8001](http://localhost:8001)** in your web browser.
